## ⚙️ Run Locally

Follow these steps to run the portfolio on your computer.

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm
- [Git](https://git-scm.com/)

### 1. Clone the repository

```bash
git clone https://github.com/Abh1ck/abhishek-portfolio.git
```

### 2. Navigate to the project directory

```bash
cd abhishek-portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL printed in your terminal, usually `http://localhost:5173`.

### 5. Create a production build

```bash
npm run build
```

Vite generates the production files in the `dist` directory.

> **Note:** Replace the repository URL above if your actual GitHub repository has a different name.
